# MTR4 Advanced 1.0.0 —— 发布产物（历史版本）

最早发布的版本，**只支持 Minecraft 1.20.1 + Fabric**（当时还没有多版本/Forge 构建）。

- 文件：`MTR4Advanced-1.0.0.jar`
- 包名还是旧标识 `cn.nansai.mtrspeed`，mixin 前缀 `mtrspeed$`（1.0.2 起已改为 `cn.nansai.mtr4advanced` / `mtr4a$`）
- mod id `mtr4-advanced`（与后续版本一致）
- 前置：Minecraft 1.20.1 + Fabric Loader + MTR 4.0.4

**已被 1.0.2 取代**，这里仅作归档。新装请用 `../1.0.2/` 里对应自己环境的 jar。
