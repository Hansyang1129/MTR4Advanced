# MTR4 Advanced —— 发布归档

一个**模组版本一个文件夹**，每个文件夹里是该版本的全部构建 + 校验清单。

| 文件夹 | 内容 | 支持的 MC 版本 | 加载器 |
| --- | --- | --- | --- |
| [`1.1.0/`](1.1.0/) | 10 个 jar | 1.18.2 / 1.19.2 / 1.19.4 / 1.20.1 / 1.20.4 | Fabric + Forge |
| [`1.0.4/`](1.0.4/) | 10 个 jar | 同上 | Fabric + Forge |
| [`1.0.2/`](1.0.2/) | 10 个 jar | 同上 | Fabric + Forge |
| [`1.0.1/`](1.0.1/) | 10 个 jar | 同上 | Fabric + Forge |
| [`1.0.0/`](1.0.0/) | 1 个 jar | 1.20.1 | Fabric |

**新装请用最新版**（当前 `1.1.0/`）：刷子界面里可直接改已有轨道的线路限速；站台可按「交路 × 站台」
设置延迟开门 / 提前关门 / 技术停车。1.0.4 起同时支持 MTR 4.0.4 与 4.0.5。

命名规则：`MTR4Advanced-<模组版本>-<MC版本><加载器>.jar`
每个版本文件夹里的 `SHA1SUMS.txt` 是该文件夹所有 jar 的 SHA-1。

许可：MIT。MTR 与本模组无隶属关系；本归档**不包含** MTR 本体。
