# 变更日志

版本号在三个地方手工同步：`src/main/resources/fabric.mod.json` 的 `version`、
`build.py` 里的 `OUT_JAR` 文件名、以及 README / 本页的说明。改版本时三处都要动。

---

## [1.0.2] —— 2026-10-06

**内部标识统一**：包名与 mixin 前缀跟上了 1.0.0 的改名，功能无变化。

| 项 | 旧 | 新 |
| --- | --- | --- |
| Java 包名 | `cn.nansai.mtrspeed` | `cn.nansai.mtr4advanced` |
| mixin 内部前缀（`@Unique` 字段/方法、访问器） | `mtrspeed$` | `mtr4a$` |
| 静态常量前缀 | `MTRSPEED$` | `MTR4A$` |

**刻意没动的**（改动它们会伤到玩家）：

- 序列化 key `trainMaxSpeedKilometersPerHour` / `maxSpeedFollowsDeviation` —— 这两个字符串写进存档与网络包，
  改名等于把所有玩家已配置的侧线限速静默清零。
- mod id（`mtr4-advanced` / `mtr4advanced`）、配置文件名、jar 命名 —— 1.0.0 刚统一过，再改只有迁移成本。

包名与前缀不参与序列化，所以这次改名不影响任何现有存档 / 配置。

## [1.0.1] —— 2026-10-06

**多版本发布**：从「只支持 1.20.1 Fabric」扩展到 **5 个 MC 版本 × 2 个加载器**，共 10 个发布产物。

| 项 | 说明 |
| --- | --- |
| 新增 MC 版本 | 1.18.2 · 1.19.2 · 1.19.4 · 1.20.4（原只有 1.20.1） |
| 新增加载器 | **Forge**（原只有 Fabric） |
| 新脚本 | `build_release.py`：逐目标编译 + 逐目标生成平台元数据 + 逐目标校验注入点 |
| 命名 | `MTR4Advanced-1.0.1-<MC版本><Fabric\|Forge>.jar` |
| 功能变更 | **无**，纯平台/版本扩展（源码逻辑与 1.0.0 一致） |

平台差异（脚本自动处理）：

- Fabric 用 `fabric.mod.json` 声明 mixin；**Forge 靠 jar MANIFEST 的 `MixinConfigs` 属性**加载 mixin 配置。
- Forge 的 modId 不能用连字符 → `mtr4advanced`；Fabric 仍是 `mtr4-advanced`。
- **编译期 stub 需要正确继承层级**：Fabric 版 MTR 把 Minecraft 类型藏在占位符 `class_339` 后面，
  Forge 版直接用真实类名（`net.minecraft.client.gui.components.AbstractWidget`），
  所以 Forge 目标的 stub 层级错了会报 `TextFieldWidgetExtension cannot be converted to AbstractWidget`。
  （`build.py` 里的同一处 stub 生成逻辑也一并修了。）

各目标验证结果：**10/10 编译通过 + 注入点 18/18 全 OK**（各自对着该版本的 MTR 4.0.4 字节码校验）。

> ⚠️ 本版只做了**编译期 + 注入点**验证，没有在真实游戏里逐个版本启动测试。
> 1.20.1 Fabric 是唯一的运行时验证过的组合。

## [1.0.0] —— 2026-09

首个可用版本。三个特性：

1. **提速由车尾控制**：加速目标取「列车占用区间 `[车尾, 车头]` 内的最低线路限速」。
2. **侧线「列车最高时速」**：侧线新增字段 + 「跟随晚点浮动」开关；默认硬顶，任何情况下不突破。
3. **时刻表按车型长度推算**（`apply-vehicle-length-to-time-segments`）：
   把车尾控制提速带来的延迟算进计划时间，消除结构性晚点。

配套：

- 侧线界面新增四行配置区（相对布局，跟随 MTR 自身的 `textWidth` 与最后一个原生控件）。
- 「复制到车场其他侧线」按钮，按 **40 条一批**发送（防止大车场单包超限导致整包被拒）。
- 四个配置项：`tail-controlled-acceleration`、`default-max-speed-kmh`、
  `apply-max-speed-to-time-segments`、`apply-vehicle-length-to-time-segments`。
- 离线构建脚本 `build.py`（只需 JDK 17+）与注入点校验脚本 `tools/check_targets.py`。

## 改名记录 —— 2026-09-19

原名 **MTR Train Speed** → 现名 **MTR4 Advanced**。

| 项 | 旧 | 新 |
| --- | --- | --- |
| mod id | `mtr-train-speed` | `mtr4-advanced` |
| jar | `mtr-train-speed-1.0.0.jar` | `MTR4Advanced-1.0.0.jar` |
| 配置文件 | `config/mtr-train-speed.properties` | `config/mtr4-advanced.properties` |
| mixin 配置 | `mtr-train-speed.mixins.json` | `mtr4-advanced.mixins.json` |

**当时未改**：Java 包名与 mixin 内部前缀（纯内部标识）—— 已在 [1.0.2](#102--2026-10-06) 统一为
`cn.nansai.mtr4advanced` 与 `mtr4a$`。

> 升级时**必须删掉旧的 jar**，否则两份 Mixin 会对同一目标重复注入。
> 旧配置文件不会自动迁移，字段要手工搬（旧版只有 3 个键）。
